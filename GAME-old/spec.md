# Specification for procedural top down shooter

## General description

The player spawns in the center of a randomly generated map. The map consists of three types of regions generated by a noise function, with two treshold constants to separate them. The types of regions are:

1. cliff tiles (high noise vaules)
2. walkable tiles (medium and low values)
3. enemy spawn location tiles (low values) - each spawn location tile has a small, constant value of actually spawning an enemy

The player has a small (text based) compass at one corner of the screen specifying in what cardinal direction the nearest enemy is (whether on or off screen). The player's mission is to clear the map of all enemies.
The player is able to shoot projectiles in the direction of movement to kill the enemies and must avoid touching the enemies.

## Technologies

- random map generation based on a noise function -> populates enemy entity array on second pass
- enemy entity array (contains all enemies from the start of the game)
- player movement and scrollable viewport (map is larger than viewport)
- bounded player projectile entity array (contains all bullets fired by player)
- linear enemy movement towards player (only moves if on screen)

## Program overview

```c

// ---------- GLOBALS ----------
const int MAX_MAP;
tile* map; // map array (data is in .bss)
int map_size_x, map_size_y; // full map size is map_size_x*map_size_y


const int MAX_ENEMIES;
enemy* enemies; // enemies array (data is in .bss)
int enemies_size;

int player_dx, player_dy;
int player_x, player_y;
int viewport_x, viewport_y; // in-world position of viewport corner
int VIEWPORT_X_SIZE, VIEWPORT_Y_SIZE; // set in initialize at first run -> no window resizing afterwards


const int MAX_PROJECTILES;
projectile* projectiles; // projectiles array (data is in .bss)
int projectiles_size;


const int PLAYER_TIMESCALE;
const int SHOOTING_SPEED;
const int PROJECTILE_TIMESCALE;
const int ENEMY_TIMESCALE;
// For generate_map:
const int CLIFF_TRESHOLD; // values above this are marked as unwalkable
const int ENEMY_TRESHOLD; // values below this are marked as enemy spawn location


// ---------- GAME LOOP ----------
/*
Generates map, spawns enemies, initializes terminal view.
*/
void initialize();

/*
Runs in a loop until death or all enemies are defeated. Should be ran at equal intervals.
Calls process_input, move_projectiles, move_enemies, render in this order.
*/
void tick(int tick_no);

/*
Resets terminal, prints score.
*/
void game_over(bool won);


// ---------- GENERATION ----------

/*
Used in initialize.
Sets the globals map_size_x and map_size_y.
Fills global map to an array on of size x_size*y_size*sizeof(tile) using the noise function.
Does a flood fill check before setting enemy spawn tiles and only spawns inside reachable tiles.
noise -> unwalkable+enemy spawn -> flood-fill from center -> remove spawn bit if unreachable
*/
void generate_map(int x_size, int y_size);

/*
Used in generate_map.
This function will be copied from the internet for obvious reasons.
Return:
  Value of tile at that location. 
*/
int get_noise_val(int x, int y, int seed);


/*
Used in initialize.
Spawns enemies on enemy spawn location tiles (iterates map array).
Parameters:
  chance - chance to spawn an enemy on a spawn location tile (0-255)
*/
void spawn_enemies(int chance);


/*
Used in move_player, move_projectiles, move_enemies.
*/
bool is_walkable(int x, int y);

/*
Used in is_walkable, generate_map, spawn_enemies.
*/
int map_idx(int x, int y);


// ---------- PLAYER ----------

/*
Used in tick.
Non-blocking. Get wasd for movement and space for shooting.
Calls move_player and shoot.
*/
void process_input();

/*
Used in get_input.
Moves the player by the specified amount. Does not move player if new position is unwalkable.
Uses a global constant PLAYER_TIMESCALE to only move player on ticks divisible by it.
*/
void move_player(int dx, int dy, int tick);

/*
Used in get_input.
Inserts a projectile to the projectile array with the specified velocities at the first available slot. (marks it active)
Uses a global constant SHOOTING_SPEED to only shoot on ticks divisible by it.
*/
void shoot(int tick);

/*
Used in tick.
Moves all projectiles by their respective velocities. Deletes (marks inactive) projectile if new position is unwalkable, or adjacent to enemy (in which case it also marks enemy inactive!!!!! - thankfully, score can be inferred by number of active enemies).
Uses a global constant PROJECTILE_TIMESCALE to only move projectiles on ticks divisible by it.
*/
void move_projectiles(int tick);


// ---------- ENEMIES ----------

/*
Used in tick.
Moves all enemies in the direction of the player if enemy is in viewport.
Does not move if next position is unwalkable.
Uses a global constant ENEMY_TIMESCALE to only move enemies on ticks divisible by it.
Return:
  0 - if not touching player
  1 - if touching player (game_over)
*/
bool move_enemies(int tick);

/*
Used in render.
Return:
  Direction (0=N, 1=NW, 2=W, 3=SW, 4=S, 5=SE, 6=E, 7=NE)
*/
int find_nearest_enemy();

// ---------- RENDERING ----------

/*
Used in tick.
Updates viewport global values and renders everything on screen.
*/
void render();
```

### Structs

Number of bytes to the left and description to the right.

```txt
tile: 
  1 - 0,0,0,0,0,is_reachable,is_unwalkable,is_enemy_spawn
enemy:
  2 - x
  2 - y
  1 - is_active
  (1 - padding)

projectile:
  2 - x
  2 - y
  2 - x_velocity
  2 - y_velocity
  1 - is_active
  (1 - padding)
```

## Non technical notes

- enemy spawn locations are rendered with a different color from normal walkable tiles to warn the user
